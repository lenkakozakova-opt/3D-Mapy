# 3D mapy túr

Veřejně hostované interaktivní 3D mapy (GitHub Pages). Zdrojová data a build jsou v soukromém repu Projekty, sem se kopírují jen hotové stránky.

- `index.html` – rozcestník
- `zugspitze/index.html`, `zugspitze/mobil.html` – Zugspitze přes Höllental (plná a odlehčená verze)
- `triglav/index.html`, `triglav/mobil.html` – Triglav přes Plemenice (plná a odlehčená verze)

Aktualizace: v repu Projekty spustit build a zkopírovat `index.html` a `*-mobil.html` do příslušné složky zde.
